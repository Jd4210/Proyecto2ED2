# Proyecto2ED2
Este proyecto implementa comunicación entre una NUCLEO-F446RE y un ESP32 utilizando UART, SPI e I2C. Desde un menú por comunicación serial, el usuario puede enviar comandos para controlar LEDs conectados al ESP32 mediante SPI o solicitar la lectura de un sensor analógico mediante I2C. Además, la NUCLEO utiliza TIM2 para generar una señal cuadrada cuyo tiempo en estado HIGH y LOW depende del valor ingresado por el usuario. El sistema está diseñado para que las diferentes funciones puedan operar de forma conjunta.
